# ScholarSphere AI
**Your Gateway to Global Education**

## Project Description
ScholarSphere AI is an AI-powered platform that helps students find suitable international universities and scholarships. It also provides personalized study plans and application assistance.

## Objectives
- Recommend suitable universities and scholarships.
- Explain eligibility based on available criteria.
- Generate adaptive IELTS, TOEFL, and GRE study plans.
- Create daily tasks and analyze preparation progress.
- Assist with SOP, CV, and professor-email drafts.
- Provide AI counselor guidance and application tracking.
  
## Proposed Features
- AI-based scholarship and university recommendations.
- Student profile analysis and eligibility checking.
- Personalized IELTS, TOEFL, and GRE study plans.
- Automatic daily to-do lists and progress analysis.
- SOP, CV, and email assistance.
- AI counselor chatbot.
- Application and deadline tracking.

## Technology Stack
- **Frontend:** React.js, HTML, CSS, JavaScript
- **Backend:** Node.js, Express.js
- **Database:** MongoDB
- **AI Integration:** Gemini API
- **Tools:** Git, GitHub, Figma
