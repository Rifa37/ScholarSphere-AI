# ScholarSphere Ai - Project Overview

ScholarSphere Ai is an AI-powered study abroad assistance platform.

## Main Modules

1. Student Authentication
2. AI Scholarship Finder
3. University Recommendation
4. AI Application Assistant
5. AI Student Counselor
6. AI Adaptive Study Planner
7. Application Tracker

## Main Objective

To help students plan and manage their international education journey using Artificial Intelligence.
